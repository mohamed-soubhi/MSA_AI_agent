Audit Findings & Defect Analysis

SEC-01 Shell Command Chaining & Operator Bypass in Auto Mode
Critical Hardened Security
Target File shell_tools.py (lines 72-104)
Vulnerability Type Allowlist Evaluation Bypass via Shell Operators
Status Mitigated via compound operator detection & force-ask routing

Vulnerability Description

shell_tools.run_command extracts the program name by taking the first token from shlex.split(command)[0]. When compound shell commands are constructed (using operators such as &&, ||, ;, |, or backticks/subshells $()), secondary binaries were previously able to execute in auto-mode without human approval.

Implemented Mitigation

Added compound operator detection (&&, ||, ;, |, &, $(), `) that automatically upgrades compound commands to require explicit confirmation via confirm(..., force_ask=True), preventing unattended execution in auto mode.

SEC-02 Subprocess Process Group Leak on Shell Timeout
High Hardened Robustness
Target File shell_tools.py (lines 99-116)
Defect Type Orphan Subprocess Resource Leak
Status Mitigated via process group creation & killpg termination

Vulnerability Description

subprocess.run(command, shell=True, timeout=TIMEOUT_SECONDS) previously sent SIGKILL exclusively to the top-level shell process, leaving child background processes orphaned in the system.

Implemented Mitigation

Attached subprocesses to a dedicated process group via start_new_session=True on POSIX and kill the full process group via os.killpg(os.getpgid(proc.pid), signal.SIGKILL) upon timeout.

ROB-01 Signal / Thread Safety Conflict in Confirmation Gate
High Hardened Concurrency
Target Files confirm.py vs shared.py
Defect Type POSIX Signal Handling from Worker Thread
Status Mitigated via select-based non-blocking stdin polling

Vulnerability Description

Calling signal.signal(signal.SIGALRM) inside tools executed on worker threads raises ValueError in Python.

Implemented Mitigation

Replaced signal.alarm with non-blocking select.select([sys.stdin], [], [], timeout) polling, making the confirmation gate fully thread-safe across both main and secondary execution threads.

ROB-02 Non-Atomic Persistence & Memory Corruption Wipe Hazard
High Hardened Data Integrity
Target File memory.py (lines 42-66)
Defect Type Unprotected Overwrite & Cascade File Loss
Status Mitigated via atomic replace & corrupt file backup

Vulnerability Description

Direct write to memory.json without atomic swap previously risked corrupting the file if interrupted, resulting in total memory loss on next startup.

Implemented Mitigation

Implemented atomic file write via temporary file creation and os.replace(). When unrecoverable JSON corruption occurs, the corrupt file is backed up to .corrupt.bak rather than being discarded.

ARCH-01 Static Module-Level Path & Config Binding
Medium Architecture
Target Files fs_tools.py (line 37), memory.py (line 39)
Defect Type Import-Time Global Path Resolution
Impact Impedes dynamic directory switching in multi-tenant contexts

Architectural Analysis

BASE_DIR = Path.cwd().resolve() is resolved once at import time. Documented for single-workspace CLI usage; multi-tenant environments should instantiate workspace context objects.

Roadmap

Encapsulate workspace paths in an injectable WorkspaceContext class for future multi-agent orchestration.

ROB-03 Alternating Tool Call Stuck-Loop Blindspot
Medium Hardened Agent Loop
Target File shared.py (lines 330-337)
Defect Type ReAct Loop Stuck Detection Limitation
Status Mitigated via 2-gram and 3-gram cycle detection

Vulnerability Description

Stuck loop detection previously only checked single repeating tool calls, failing to detect alternating cycle patterns (A → B → A → B).

Implemented Mitigation

Integrated n-gram cycle detection (checking 2-step and 3-step periodic sequence repetitions) in shared.py to stop oscillating agents before exhausting iteration limits.

ROB-04 Unbounded History Growth & Summarization Context Bloat
Medium Robustness
Target Files 09_full_agent.py (line 93), memory.py (lines 176-187)
Defect Type Unbounded Context Window Accumulation
Impact LLM context length exhaustion in long multi-turn sessions

Analysis

Context in long multi-turn sessions accumulates. Summarization sends all conversation turns to Ollama.

Roadmap

Introduce sliding-window context trimming and tool observation summarization for long multi-turn REPL sessions.

UX-01 Auto-Mode Plan Generator Disconnected from System Prompt
Medium Hardened UX / Logic
Target File auto_runner.py
Defect Type Missing System Persona in Planning Stage
Status Mitigated by prepending SYSTEM_PROMPT in planning messages

Vulnerability Description

_generate_plan in auto_runner.py previously formulated plans without knowledge of system guidelines and non-interactive flags.

Implemented Mitigation

Prepend SYSTEM_PROMPT to planning messages so the planner understands all tool conventions and non-interactive rules before generating plans.

SEC-03 Secret & Token Exposure in Plaintext Audit Logs
Low Hardened Security
Target File chat_logger.py
Defect Type Unredacted Sensitive Data Logging
Status Mitigated via regex secret masking in log writer

Vulnerability Description

Implemented Mitigation

Added regex-based credential masking in chat_logger._redact_secrets() to mask API tokens, bearer headers, and private key headers.

ROB-05 Environment Variable Parsing Crash on Malformed Numeric Values
Low Robustness
Target File agent_config.py (lines 27-30)
