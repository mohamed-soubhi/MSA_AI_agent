🏛️ System Architecture Topology

High-level structural breakdown of the sandboxed AI agent system. Highlights the dual interaction surfaces (Terminal CLI & Web SPA), central asynchronous bridge layer, hardened ReAct execution engine, 4-layer security boundaries, and isolated persistence stores.

Dual Interaction Surfaces

The system provides two interchangeable execution interfaces that share the exact same underlying 9 tools, sandbox enforcement, and confirmation gates:

  • CLI REPL (CLI_agent.py): Standard input/output terminal loop supporting both interactive step mode and plan-once auto mode.
  • Web SPA (BE/app/static/chat.html): FastAPI + SSE + fetch streaming interface with visual activity inspector and remote HTTP confirmation modals.
  • Interactive Config Editor (BE/app/static/config.html): Real-time inspector and editor for agent and backend settings with drift-safe default extraction.

Sandboxed Isolation Architecture

Structural separation guarantees the agent cannot tamper with its own source code or persistence records:

  • Sandbox Root (workspace/): All file operations and shell commands are locked strictly inside BASE_DIR.
  • Source Code (agent/ & BE/): Sits outside workspace/. resolve_path() blocks all attempts to navigate upwards.
  • Persistent Memory (memory.json) & Logs (logs/*.jsonl): Reside at project root, physically isolated from tool-level filesystem writes.

🔒 Security Architecture & Defense-in-Depth

Deep-dive analysis of the 10 structural security and robustness decisions implemented across the codebase.

1. Sandbox Separation (SEC-FIX)

BASE_DIR is resolved relative to agent_config.py as PROJECT_ROOT / "workspace" rather than Path.cwd(). Prevents the agent from modifying its own Python files even if started from the repository root.

2. Chained Shell Operator Detection (SEC-01)

_is_compound() scans for &&, ||, ;, |, &, $(, `. Prevents hidden subcommands from slipping past Layer 1 allowlists without human oversight.

3. Subprocess Process Group Isolation (SEC-02)

start_new_session=True assigns subprocesses their own process group ID. On timeout, os.killpg(SIGKILL) terminates the entire subtree, preventing orphaned background daemons.

4. JSONL Secret Masking (SEC-03)

_mask_secrets() recursively redacts RSA private keys, JWT tokens, OpenAI API keys, AWS keys, GitHub tokens, and Bearer headers before disk serialization.

5. Stdin Concurrency & Orphan Protection (BUG-FIX)

A process-wide non-blocking _stdin_lock prevents racing terminal input threads. On timeout, the lock is retained to isolate abandoned daemon readers.

6. Atomic Memory File Replacement (ROB-02)

memory.py writes to memory.json.tmp{pid} and swaps atomically via os.replace(). Corrupt files are automatically backed up as .corrupt.bak.
