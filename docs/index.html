Capabilities

Engineered for Robustness & Security

Every subsystem was architected to eliminate silent failure modes, sandbox breakouts, and stuck-in-loop states.

🛡️

Defense-in-Depth Sandbox

Filesystem I/O strictly restricted to workspace/. Intercepts compound shell chaining (&&, ||, ;), protects against Windows reserved device names, and kills orphaned subprocess groups via os.killpg.

⚡

Dual Interaction Interfaces

Full terminal REPL (Step Mode + Auto Plan Mode) and a modern FastAPI Web Chat SPA with real-time Server-Sent Events (SSE), tool execution logs, and sandboxed HTML previews.

🧠

Cross-Session Durable Memory

Persistent JSON memory featuring atomic file replacement (os.replace), corrupted backup recovery (.corrupt.bak), tag-based recall, and automated all-time token usage analytics.

🌐

Config-Gated Web Tools

Hosted internet search and web page fetching via Ollama's cloud API. Eliminates local SSRF risks, enforces confirmation gates, and isolates API credentials from disk storage.

🎛️

Live Settings & Memory UI

Web-based Config Editor with in-process module reloading (config_reload.py), 5-digit unlock confirmation code, single-click directory picker, and model catalog browser.

🔄

ReAct Loop Defense

Hardened ReAct execution core equipped with 1-gram, 2-gram, and 3-gram alternating stuck-loop detection, watchdog timers, and seamless unlimited mode for data pipelines.

Tool Registry

Hardened 11-Tool Execution Suite

Assembled through tools_registry.py to ensure 100% feature parity between CLI and Web interfaces.

read_file(path: str) -> str

Reads the content of a file located strictly within the workspace/ sandbox root.

  • Safety Invariant: Validated by fs_tools.resolve_path(). Blocks path traversal (../) and symlink escapes.
  • Normalization: NFKC Unicode normalization prevents visual spoofing.
write_file(path: str, content: str) -> str

Writes text content to a sandboxed file, creating parent directories safely if necessary.

  • Gate: Requires user approval via confirm().
  • Isolation: Blocks writes outside workspace/ and defends against Windows reserved device names (CON, PRN, AUX, NUL).
run_command(command: str) -> str

Executes shell commands in a dedicated subprocess group rooted inside workspace/.

  • 4-Layer Gate: (1) Allowlist check → (2) Blocklist check → (3) Compound operator check (forces ask on &&, ||, ;) → (4) Subprocess timeout with os.killpg group kill.
web_search(query: str, max_results: int | None = None) -> str

Searches the public web via Ollama's hosted search API and returns ranked titles, URLs, and snippets.

  • Security: Proxied through Ollama Cloud; zero local SSRF surface. Gated by WEB_TOOLS_ENABLED and confirm().
web_fetch(url: str) -> str

Fetches page contents from an absolute HTTP/HTTPS URL and converts it to formatted Markdown.

  • Safety: Enforces http:// / https:// scheme; truncates output at WEB_FETCH_MAX_CHARS ceiling.
ask_human(question: str) -> str / ask_human_choice(question: str, options: list[str]) -> str

Conversational Human-in-the-Loop clarification tools when model instructions are ambiguous.

  • Routing: Routes to terminal stdin in CLI mode; pushes SSE event and suspends worker thread in Web mode.
remember_fact(fact: str, tags: list[str] | None = None) -> str

Persists durable facts across sessions into memory.json with timestamp metadata.

  • Robustness: Atomic file replacement (os.replace) guarantees corruption-free writes.
