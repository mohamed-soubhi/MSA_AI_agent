⚡ Quickstart & uv Environment Setup 
# 1. Clone repository & install dependencies using uv
git clone https://github.com/mohamed-soubhi/MSA_AI_agent.git
cd MSA_AI_agent
uv sync --group dev

# 2. Launch the Web Backend (Chat & Config UI at http://localhost:8000/chat)
./run_be.sh          # Windows: run_be.bat

# 3. Or launch the Terminal CLI Agent REPL
./run_cli_agent.sh   # Windows: run_cli_agent.bat
